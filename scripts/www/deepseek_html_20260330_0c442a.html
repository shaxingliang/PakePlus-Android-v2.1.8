📖 计算原理

标准曲线方程：Y = m·X + b
其中 Y = Ct值，X = log₁₀(初始DNA拷贝数)，m = 斜率，b = 截距。

➜ 已知Ct值，通过公式 X = (Ct - b) / m 得到X，再计算 拷贝数 = 10^{X}。

  • ✅ 斜率 (m) 反映扩增效率，理想范围 -3.1 至 -3.6 (效率90%~110%)
  • ✅ Ct值越小，初始模板拷贝数越高
  • ✅ 本工具专用于 Ct值 → 拷贝数 单向计算，界面专为手机操作优化
